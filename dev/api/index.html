FixedPointArithmetic — Module

Binary fixed-point numbers for simulating fixed-point signal processing.

A fixed-point type Fx has a word length, a fraction length, a rounding mode and an overflow mode, created with fixed. Operations follow the model of hardware fixed-point types such as ap_fixed: products keep full precision, sums keep the format of their operands, and rounding and overflow happen when a value is converted to another format, which includes storing it into an array of that format.

Operations follow the model of hardware fixed-point types such as ap_fixed: products keep full precision, sums keep the format of their operands, and rounding and overflow happen when a value is converted to another format, which includes storing it into an array of that format.

FixedPointArithmetic.Saturate — Constant
Saturate

Overflow mode that clamps to the largest or smallest representable value, -2^(W-1) to 2^(W-1) - 1 in units of the least significant bit for word length W.

source
FixedPointArithmetic.SaturateSymmetric — Constant
SaturateSymmetric

Overflow mode that clamps to a range symmetric around zero, -(2^(W-1) - 1) to 2^(W-1) - 1 in units of the least significant bit, so that negation and abs never overflow. The usual choice for soft bits such as int8 LLRs.

source
FixedPointArithmetic.Wrap — Constant
Wrap

Overflow mode that keeps the low word-length bits of the two's complement representation, as integer hardware does without saturation logic.

Core.Type — Method
(::Type{X})(x::AbstractFloat) where {X<:Fx}

Quantize x to the fixed-point type X with its rounding and overflow modes. The rounding is exact with respect to the value of x. NaN becomes 0, and so do ±Inf with Wrap.

FixedPointArithmetic.Fx — Type
Fx{W,F,R,O,T} <: Real

A signed binary fixed-point number with word length W bits and F fraction bits: the value i / 2^F of an integer i in the W-bit two's complement range. R is the rounding mode (a Base RoundingMode) and O the OverflowMode applied when a value is converted to this format. T is the smallest signed integer type with at least W bits, which stores i. Create the type with fixed rather than spelling out the parameters.

W is at most 64, and F is between 0 and W.

Examples

julia> Q15 = fixed(16, 15)
Fx{16, 15, RoundDown, Saturate, Int16}

julia> x = Q15(0.3)
Fx{16, 15, RoundDown, Saturate, Int16}(0.29998779296875)

julia> rawvalue(x)
9830

FixedPointArithmetic.OverflowMode — Type
OverflowMode

How a value outside the range of a fixed-point format is brought back into it: Wrap, Saturate or SaturateSymmetric. The rounding of values between two representable ones is a Base RoundingMode instead, see fixed.

Base.Math.ldexp — Method
ldexp(x::Fx, e::Integer)

x * 2^e in the format of x: a left shift goes through the overflow mode, and a right shift rounds with the rounding mode. This is the scaling step of block floating point, for example an exponent applied to a whole block of samples. For floating-point x, ldexp is the exact Base function, so generic code can call it for both.

Base.sqrt — Method
sqrt(x::Fx)

The square root of x in its own format, correctly rounded with its rounding mode and brought into its range with its overflow mode (only formats without integer bits, F == W, can overflow). Negative values give 0, as NaN converts to 0, so that sqrt never throws. The integer square root is computed bit by bit, two bits of the operand per step, as a hardware square-root unit does.

Examples

julia> sqrt(fixed(16, 15)(0.25))
Fx{16, 15, RoundDown, Saturate, Int16}(0.5)

julia> sqrt(fixed(16, 8; rounding=RoundNearest)(2))
Fx{16, 8, RoundNearest, Saturate, Int16}(1.4140625)

FixedPointArithmetic.divide — Method
divide(::Type{Y}, a, b) where {Y<:Fx}

The quotient a / b of fixed-point values or integers in the format Y: the exact quotient, rounded once with the rounding mode of Y and brought into its range with its overflow mode. Division by zero gives what converting ±Inf gives (the largest or smallest value with saturation, 0 with Wrap), and 0/0 gives 0, so that divide never throws.

a / b is divide(typeof(a), a, b): the quotient keeps the format of the numerator, as sums keep the format of their operands. With an integer numerator, n / b takes the format of b, and inv(x) is 1 / x.

Integer operands far outside the range that matters for the result are clamped first, which keeps the results exact except for quotients that overflow a Wrap format. Dividing two integers converts through Rational and is meant for constants, not for kernels.

Examples

julia> Q15 = fixed(16, 15; rounding=RoundNearest);

julia> divide(Q15, Q15(0.25), Q15(0.75))
Fx{16, 15, RoundNearest, Saturate, Int16}(0.333343505859375)

julia> Q15(0.75) / Q15(0.25)  # 3 saturates in Q15
Fx{16, 15, RoundNearest, Saturate, Int16}(0.999969482421875)

julia> divide(fixed(16, 13; rounding=RoundNearest), Q15(0.75), Q15(0.25))
Fx{16, 13, RoundNearest, Saturate, Int16}(3.0)

FixedPointArithmetic.fixed — Method
fixed(W::Integer, F::Integer; rounding=RoundDown, overflow=Saturate)

The fixed-point type Fx with word length W bits, of which F are fraction bits, so that its least significant bit has weight 2^-F. rounding is one of RoundDown (floor, what an arithmetic right shift does), RoundUp, RoundToZero, RoundNearest (ties to even), RoundNearestTiesAway and RoundNearestTiesUp (round half up, what adding half an LSB before the shift does). overflow is Wrap, Saturate or SaturateSymmetric.

Both modes apply when a value is converted into this type, including when it is stored into an array of it.

Examples

julia> fixed(8, 0; overflow=SaturateSymmetric)  # int8 bits in -127:127
Fx{8, 0, RoundDown, SaturateSymmetric, Int8}

julia> fixed(6, 2; rounding=RoundNearest)        # 6-bit values with step 0.25
Fx{6, 2, RoundNearest, Saturate, Int8}

FixedPointArithmetic.fromraw — Method
fromraw(::Type{X}, i::Integer) where {X<:Fx}

The value of fixed-point type X with stored integer i, for example to read integer samples from a file or from another implementation. An i outside the word length is brought into it with the overflow mode of X.

Examples

julia> fromraw(fixed(16, 15), 16384)
Fx{16, 15, RoundDown, Saturate, Int16}(0.5)
