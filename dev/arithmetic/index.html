Arithmetic model

The model follows hardware fixed-point types such as ap_fixed and ac_fixed, and MATLAB's fimath with full precision products and KeepLSB sums.

OperationResult
X(x), convert(X, x), storing into an array of Xx rounded with the rounding mode of X, then brought into its range with its overflow mode. Never throws: NaN becomes 0, and so do ±Inf with Wrap.
a + b, a - b, -a, abs(a) of one formatthe same format, with its overflow mode. Loops like acc += x keep their type; choose the accumulator format by the type of acc.
a * bexact, in a format with the word and fraction lengths added (at most 64 bits)
two formats with the same modespromoted to the format that holds both exactly; the result keeps it
formats with different modesno promotion: convert explicitly
a + n, a * n, a < n with an integer nexact, in the format of a
a + 0.5, a < 0.1, … with a floatArgumentError. Write the constant as X(0.5), which also works for float X.
divide(Y, a, b)the exact quotient, rounded once to the format Y. Division by zero gives what ±Inf converts to, and 0/0 gives 0.
a / b, inv(a)divide(typeof(a), a, b): the quotient keeps the format of the numerator, as sums keep the format of their operands, and saturates when it does not fit. n / b with an integer n takes the format of b.
a / b of complex valuesa·conj(b) / abs2(b) with exact products, one rounding per component, in the format of a
sqrt(a)the exact root, rounded once, in the format of a. Negative values give 0.
exp, log, sin, atan, abs(::Complex), angle, cis, ^p, and complex sqrt, exp, …ArgumentError. Base would compute them in floating point; a fixed-point algorithm needs its own method. x^2 works.
ldexp(a, e)a·2^e in the format of a, with its rounding and overflow modes: the scaling step of block floating point
float(a), Float64(a)the exact value when the float has enough significand bits

Rounding and overflow modes

Rounding modes are the Base ones: RoundDown (floor, an arithmetic right shift), RoundUp, RoundToZero, RoundNearest (ties to even), RoundNearestTiesAway and RoundNearestTiesUp (round half up). Overflow modes are Wrap, Saturate and SaturateSymmetric.

Raw values

The stored integer is available with rawvalue, and fromraw builds a value from one, for example to compare with integer samples from another implementation.
